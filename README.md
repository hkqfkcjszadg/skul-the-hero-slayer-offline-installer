## About

Skul: The Hero Slayer is a roguelite action platformer by SouthPAW Games where players control Skul, a small skeleton on a quest to rescue the Demon King. By equipping different skulls, players transform into various characters with unique abilities. With over 150 playable skull types, randomized stages, and challenging boss fights, Skul offers extensive replayability and exciting combat variety.

## Common Problems & Limitations

- **Roguelite Grind** — Permanent upgrades require many completed runs
- **Difficulty Wall** — Later worlds significantly increase in challenge
- **Skull RNG** — Strong run requires favorable skull drops
- **No Official Multiplayer** — Single-player experience only
